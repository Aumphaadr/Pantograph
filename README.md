# Пантограф

Открыть онлайн: [https://aumphaadr.github.io/Pantograph/](https://aumphaadr.github.io/Pantograph/)

Снимает контур с растровой картинки — обычно сгенерированной ИИ: иконку
превращает в SVG, лист с буквами — в шрифт `.otf`. Целиком в браузере,
без сервера, сборщика и зависимостей; единственная вендорная библиотека —
opentype.js для записи шрифтового файла.

Имя — от чертёжного прибора, копирующего рисунок с изменением масштаба:
пантограф Бентона в конце XIX века переносил нарисованную букву на пуансон.

## Запуск

Статика без сборки. Нужен любой http-сервер — из-под `file://`
ES-модули не грузятся.

```
npm run serve          # python3 -m http.server 8080
```

Затем http://localhost:8080/. При разработке `?img=путь-к-картинке`
подставляет картинку сразу, переживая перезагрузку страницы.

## Как устроена работа

Два маршрута, переключатель слева от ленты шагов. Каждый шаг показывает
своё и держит настройки рядом с тем, на что они влияют.

- **Иконка**: Картинка → Маска → Контур → Экспорт. Кроп, мягкая маска по
  цветовому расстоянию, трассировка в кривые Безье, правка узлов, SVG.
- **Шрифт**: Картинка → Маска → Буквы → Метрики → Шрифт. Лист режется на
  буквы, буквы привязываются к символам, четыре направляющие ставят метрики,
  из всего собирается `.otf` — и проба пера набирается тем самым файлом,
  который скачается.

## Что умеет

**Обводка.** Свой трассировщик: изолиния по субпиксельной маске, подгонка
Шнайдера по плотным точкам, углы ставятся в настоящие вершины. Буквам
включён канон шрифтов: узлы дуг — на экстремумах с осевыми рычагами, прямые
распознаются под любым углом, контуры-прямоугольники и эллипсы становятся
ими самими, лишние узлы удаляются пробно — везде с одним порогом, допуском
«Точности»: форма не выдумывается, из неотличимых кандидатов выбирается
самый правильный. Отдельная кнопка «Штрихом» обводит осевую линию вместо
границы — линейная иконка перестаёт быть двухконтурной «трубой». Кнопка
«Сборкой» идёт дальше: осевая собирается из примитивов — круг, прямоугольник
со скруглением и поворотом, отрезок, ломаная, путь из отрезков и дуг, пятна
заливкой, — и в SVG уходят настоящие `<rect>`, `<circle>`, `<line>` с одной
толщиной штриха. Робот с ушами и антенной — восемь примитивов. Папку
картинок по иконке на файл собирает пакетом `node refs/monoline/assemble.mjs`
(отчёт и контактный лист рядом с SVG); скрипт лежит при своём корпусе
в `refs/` и в репозиторий не входит.

**Согласование.** Буквы, задуманные симметричными, становятся симметричными
точно — по вертикальной оси, горизонтальной или обеим: половины сворачиваются
ещё на маске, контур режется по оси, и худшая сторона заменяется зеркалом
лучшей. Толщины штрихов выравниваются по всему листу; несимметричное и
разнотолщинное не трогается.

**Несколько цветов.** Слой — одни чернила: свой цвет и допуск, остальное
общее. «Разобрать цвета» находит чернила сам; спорный пиксель отходит одному
слою. Выгрузка — один SVG, слой на группу, она же слой в Inkscape; заливка
плоским чёрным или цветом с картинки.

**Мера качества.** Контур рендерится обратно в растр и сверяется с маской:
в сводке всегда стоит расхождение — средний увод края в пикселях и
потерянные куски, если они есть. Кнопка «Подобрать сам» ищет баланс: узел
стоит фиксированную долю увода края, и восемь узлов при точном контуре
берутся охотнее семи при неточном. Иконка — секунды, лист — около минуты,
найденные значения открыто встают в ползунки, любой ползунок прерывает
подбор. Обводка сверена с настоящими шрифтами (Lato, FreeSerif — контуры
и их рендер лежат в `refs/font_ref/`, в репозиторий не входят; см.
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)): узлов выходит столько же, сколько
в исходных контурах, увод от них — около 0.15 px; у каждой плитки в
подсказке — сколько узлов у этой буквы обычно.

**Правка.** Полный редактор узлов: тяга, вставка, удаление, гладкий/угловой,
отмена. У иконки — на шаге «Контур»; у буквы контур открывается двойным
щелчком по плитке, правки переживают пересчёт и хранятся в проекте.
Контуры иконок сверяются с простыми фигурами и предлагают привести себя
к ним — предлагают, а не делают молча.

**Проект.** Работа сохраняется сама; закрытая вкладка ничего не теряет.
«Выгрузить» кладёт проект в один zip вместе с картинкой — так он переезжает
между машинами. «Пакет SVG» отдаёт по файлу на букву.

## Управление

| | |
|---|---|
| перетащить файл, <kbd>Ctrl</kbd>+<kbd>V</kbd> или «Открыть картинку» | загрузить |
| протянуть ЛКМ | нарисовать кроп |
| колесо · <kbd>Shift</kbd>+перетаскивание | зум · панорама |
| <kbd>0</kbd> <kbd>1</kbd> <kbd>+</kbd> <kbd>−</kbd> | вписать · 1:1 · крупнее · мельче |
| двойной щелчок по плитке буквы | править её контур |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> · <kbd>Del</kbd> · <kbd>Esc</kbd> | отменить · удалить узлы · снять выделение |

Пипетки берут цвет с картинки с лупой — цвет виден до щелчка. У каждой
настройки кружок с вопросом. Кегль в интерфейсе нигде не ниже четырнадцати
пикселей.

## Принципы

- **Тихое враньё недопустимо.** Качество меряется, а не угадывается; проба
  пера — настоящий шрифт, а не похожая картинка; пока идёт счёт — видно, что
  он идёт; о том, что не взялось, говорится словами.
- **Допуски — в пикселях исходника** и соразмерны фигуре: умолчания и пределы
  ползунков подгоняются под размер кропа, у каждой буквы своё увеличение.
  Растут они медленнее размера — у большой картинки край известен точнее, —
  а окно угла не растёт вовсе: оно про антиалиасинг, а тот в пиксель всегда.
- **Граница владения.** Пока контур — производное от параметров, он молча
  пересчитывается. Первая правка отчуждает его: параметры замораживаются,
  вернуться можно только явной перетрассировкой.

## Тесты

```
npm test               # чистые функции, node, без зависимостей
node tests/e2e.mjs     # интерфейс целиком: свой сервер, headless-браузер
node tests/fontref.mjs # мерная линейка по шрифтам (нужна папка refs/font_ref/)
node tests/iconref.mjs # мерная линейка по иконкам (refs/solar-outline-icons/, Inkscape)
```

Листы значков от генератора режутся и обводятся пакетом:
`node tools/icon-sheets.mjs <папка>` — в папке листы PNG и MANIFEST.md
с раскладкой и именами; резы — по белым промежуткам, с проверкой, что ни один
кусок краски не лёг на разрез; на выходе `png/`, `svg/` (`viewBox 0 0 20 20`,
`currentColor`), контактные листы и REPORT.md с толщиной штриха по партиям.

Единый вес у готового набора SVG — `node tools/icon-weight.mjs <папка svg>
--out <папка> [--weight 1.4]`: у каждого куска значка край сдвигается до общей
толщины штриха, пятна и зазоры-вырезы остаются; на выходе `svg/` того же
формата, сравнение v1 | v2 по листам, палитра на светлом и тёмном и REPORT.md.
`--variants 1.3,1.5` добавляет лист с другими толщинами на выборке. Для набора,
нарисованного впритык к кадру (поле добавляет приложение), — `--frame tight`
(толщина в процентах стороны, `--weight 8.5`); `--render chrome` растрирует
любой SVG (`<rect>`, `<line>` со штрихом, стили); `--outline arcs` обводит
отрезками и дугами — для геометричных наборов; `--keep имя` оставляет значок
как был.

Сквозная проверка сама поднимает сервер, рисует картинку холстом, бросает её
на страницу, тянет кроп, правит узлы рамкой и жмёт «Скачать SVG» — то, что
руками. Без браузера честно пропускается.

Браузерное — открыть на запущенном сервере: `/tests/browser.html`,
`/tests/icons-visual.html`, `/tests/symmetry-visual.html`,
`/tests/masters-visual.html`, `/tests/sheets-visual.html`.
Автотестом «узнаваемо ли» не проверишь, только глазами.

Картинки в репозиторий не входят (см. `.gitignore`): смотровые страницы
показывают наборы `icon-crops/`, `icon-masters/`, `glyph-sheets/`,
когда те лежат рядом, и честно говорят, когда их нет.
Автотесты и `/tests/browser.html` внешних картинок не требуют.
