Шрифтовые листы

Каждый лист из glyph-sheets/ разбирается на буквы и сверяется с glyphs.txt. Строки подгоняются под известное число знаков — поэтому многоточие из трёх точек и процент из трёх частей не сбивают счёт. Требует сервера: npm run serve, затем /tests/sheets-visual.html.
