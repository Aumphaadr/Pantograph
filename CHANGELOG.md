# Пантограф: история изменений

Номера версий называет автор; пока записи идут по датам публикации.
Всё, что ещё не выложено, собирается в разделе «Не опубликовано».

---

## Не опубликовано

**Добавлено**
- **Значки интерфейса — из набора Klaarheid Icons.** Зум, свёртка панели,
  видимость и удаление слоя, пипетки, кружки подсказок, разделители шагов
  и стрелки у «Сдвига оси» рисуются значками набора — вместо символов «−»,
  «+», «‹», «›», «●», «○», «✕», «?», «↔», «↕» и самодельной пипетки. Значки
  лежат копиями файлов набора в `icons/klaarheid/`, красятся цветом текста
  и следуют теме. Обновляются командой
  `npm run icons:sync -- <папка набора> [имя …]` из локальной копии набора:
  по сети она ничего не качает, а страница не грузит значки с сайта набора.
- **Страж значков** — `tests/icons.test.js`, входит в `npm test`: разметка
  значков совпадает с файлами набора, каждое имя из кода есть в наборе
  и каждый значок набора где-то нужен, на кнопках нет символов вместо значков.
- **Страж внешних адресов** — `tests/local-only.test.js`, входит
  в `npm test`. Страница, стили, сценарии и значки не должны ничего грузить
  с других сайтов: ни с CDN, ни из репозиториев GitHub и сайтов на GitHub
  Pages, в том числе набора Klaarheid Icons. Пропускаются только ссылки
  для перехода (`<a href>`), адреса в комментариях и пространства имён XML.
  Там же проверяется, что у каждой библиотеки в `vendor/` лежит лицензия
  и строка в `THIRD-PARTY-NOTICES.md`.
- **Лицензия MIT** (`LICENSE`) и её ознакомительный перевод на русский
  (`LICENSE_RU.md`). Код можно использовать, менять и распространять, в том
  числе в коммерческих продуктах; в копиях сохраняется текст лицензии.
- **Сторонние компоненты** — `THIRD-PARTY-NOTICES.md`: opentype.js
  и вшитые в неё tiny-inflate и полифилл `codePointAt`, значки Klaarheid,
  мерные корпуса, которые в репозиторий не входят. Тексты лицензий
  библиотеки — рядом с ней, в `vendor/opentype.js-LICENSE.txt`.
- **Правила для правок** — `CONTRIBUTING.md`: где что лежит, что проверить
  перед публикацией, какие чужие файлы можно брать и как их оформлять.
- **История изменений** — этот файл.
- **Проверка в GitHub Actions:** `npm test` запускается при каждом пуше
  в `main` и на каждый pull request.
- Служебные файлы репозитория: `.gitignore`, `.editorconfig`,
  `.gitattributes`; в `package.json` — лицензия, автор, адреса сайта
  и репозитория.
- **Сверка с настоящими иконками** — мерная линейка `tests/iconref.mjs`:
  обводка отрендеренной иконки сверяется с её векторным контуром.
- **Листы значков → PNG и SVG** — `node tools/icon-sheets.mjs <папка>`:
  лист генератора с раскладкой в MANIFEST.md режется по белым промежуткам,
  с проверкой, что ни один кусок краски не лёг на разрез; каждый значок
  обводится в SVG с `currentColor`, отчёт меряет толщину штриха по партиям.
- **Единый вес набора значков** — `node tools/icon-weight.mjs <папка svg>
  --out <папка>`: край каждого куска значка сдвигается до общей толщины
  штриха, пятна и вырезы остаются. Для наборов, нарисованных впритык
  к кадру, — `--frame tight`; `--render chrome` растрирует любой SVG,
  `--outline arcs` обводит отрезками и дугами, `--keep` оставляет значок
  как был.

**Изменено**
- **Обводка сверена с векторными иконками.** Окно угла — 4 px без
  масштабирования: круглые концы штрихов больше не читаются углами. Допуски
  растут медленнее размера картинки, порог угла — 50° вместо 68°, «Мусор»
  растёт с размером линейно, а не квадратом, и не съедает мелкие точки.
  На пакете из 1181 иконки ложных углов стало 194 вместо 7665, средний
  увод края — 0.33 px.
- Мерные линейки без папки `refs/` останавливаются с сообщением, что
  сверять не с чем, а не падают с ошибкой чтения файла.

**Исправлено**
- `node tests/e2e.mjs` на машине без google-chrome падал с ошибкой запуска
  и не пробовал chromium. Теперь браузеры пробуются по списку, а без
  браузера прогон пропускается.

## 3 сентября 2026

**Добавлено**
- **Сборка из примитивов** — кнопка «Сборкой» рядом с «Заливкой»
  и «Штрихом». Осевая линия собирается из кругов, прямоугольников
  со скруглением и поворотом, отрезков, ломаных и путей из отрезков и дуг,
  пятна идут заливкой, результат сверяется растром. В SVG уходят настоящие
  `<rect>`, `<circle>`, `<line>` и `<path>` с одной толщиной штриха.
- **Сверка с настоящими шрифтами** — мерная линейка `tests/fontref.mjs`:
  каждая обведённая буква сверяется с контуром шрифта, с рендера которого
  она обведена.
- **Сколько узлов обычно у буквы** — ожидания по 154 знакам
  (`js/glyphs/priors.js`): подсказка плитки и сводка привязки говорят
  «узлов N, обычно S–T».
- **Сквозная проверка интерфейса** — `node tests/e2e.mjs`: headless-браузер
  бросает картинку, тянет кроп, правит узлы и скачивает SVG.

**Изменено**
- «Подобрать сам» ищет баланс — узел стоит 0.02 px увода края на букву, —
  а не минимум узлов: минимум утраивал увод от настоящего контура. На Lato
  узлов стало 1599 вместо 2172 (у самого шрифта 1542), увод — 0.155 px
  вместо 0.245.
- Окно угла по умолчанию — 2 px вместо 1.2.

**Исправлено**
- **Правки узлов не доходили до экспорта.** Редактор, удаление узлов, отмена
  и «Привести» меняли одну копию контура, а SVG, сводка и сохранение читали
  другую — в файл молча уходила версия до правок.
- Картинка, брошенная на шаге «Контур», выглядела так, будто ничего
  не произошло; теперь новая картинка сама возвращает на шаг «Картинка».
- Контур буквы лежал выше и левее на полпикселя увеличения, порог
  квантовал край по сетке увеличения, углы тонули в скруглении антиалиасинга:
  на Lato находилось 314 углов из 819, теперь 717.
- «Штрихом» мог потерять луч: диагональную полосу одного из наклонов
  утоньшение съедало с конца до самой развилки, и у «×» один луч пропадал
  целиком.

## 1 сентября 2026 — первая публикация

**Добавлено**
- **Маршрут «Иконка»:** Картинка → Маска → Контур → Экспорт. Кроп, мягкая
  маска по цветовому расстоянию, обводка в кривые Безье, правка узлов, SVG.
- **Маршрут «Шрифт»:** Картинка → Маска → Буквы → Метрики → Шрифт. Лист
  режется на буквы, буквы привязываются к символам, четыре направляющие
  ставят метрики, из всего собирается `.otf` — и проба пера набирается тем
  самым файлом, который скачается.
- **Свой трассировщик:** изолиния по субпиксельной маске, подгонка Шнайдера
  по плотным точкам, углы — в настоящих вершинах. Для букв — канон шрифтов:
  узлы дуг на экстремумах с осевыми рычагами, прямые под любым углом,
  контуры-прямоугольники и эллипсы становятся ими самими, лишние узлы
  удаляются пробно — везде с одним порогом, допуском «Точности».
- **Приведение к примитивам** у иконки: круг, эллипс, прямоугольник,
  скруглённый прямоугольник, многоугольник — предлагается, а не делается
  молча.
- **Симметрия и толщины.** Симметричные буквы становятся симметричными
  точно — по вертикальной оси, горизонтальной или обеим; толщины штрихов
  выравниваются по всему листу. У иконки маска складывается по найденной
  оси, рядом — оценка симметрии.
- **Несколько цветов:** слой — одни чернила со своим цветом и допуском,
  «Разобрать цвета» находит чернила сам, выгрузка — один SVG, слой
  на группу, она же слой в Inkscape.
- **«Штрихом»** — обводка осевой линии вместо границы: линейная иконка
  выходит одним контуром с толщиной штриха.
- **Мера качества:** контур рендерится обратно в растр и сверяется с маской,
  в сводке — средний увод края в пикселях и потерянные куски. «Подобрать
  сам» подбирает настройки и открыто ставит их в ползунки.
- **Редактор узлов:** тяга, вставка, удаление, гладкий и угловой узел,
  отмена. У буквы контур открывается двойным щелчком по плитке, правки
  хранятся в проекте.
- **Проект** сохраняется сам. «Выгрузить» кладёт его в zip вместе
  с картинкой, «Пакет SVG» отдаёт по файлу на букву.
- **Интерфейс:** панель настроек тянется и сворачивается, у каждой
  настройки — подсказка, кегль нигде не ниже 14 px, умолчания и пределы
  ползунков подгоняются под размер кропа.
- **Тесты:** `npm test` — чистые функции в node без зависимостей;
  браузерные и смотровые страницы в `tests/`.
